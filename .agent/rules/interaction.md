# Interaction & Communication

## Language

- ✅ **Linguistic Mirroring**: Always respond in the same language used by the user in their last request.
- ✅ If the user speaks **French** → Respond in **French**.
- ✅ If the user speaks **English** → Respond in **English**.
- ℹ️ Code language (variable names, functions) remains defined by `code-style.md` (typically English for code, French for Gherkin/Docs).

## Tone

- ✅ **Professional and Direct**: Be concise, avoid unnecessary verbiage.
- ✅ **Proactive Help**: If an error is detected, propose a concrete immediate correction.
